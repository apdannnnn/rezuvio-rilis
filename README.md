# Rezuvio: unduhan

Installer Rezuvio untuk Mac dan Windows. Rezuvio butuh kode lisensi dari pembelian di link.avenlabs.id; tanpa kode, app tidak bisa dipakai.

- Unduh: halaman **Releases**, bagian Assets.
  - Mac: `Rezuvio-1.0.1.dmg` di rilis 1.0.1. Mac Apple Silicon (M1 atau lebih baru), macOS 14 Sonoma atau lebih baru.
    Sesudah dibuka, app memperbarui dirinya sendiri ke versi terbaru.
  - Windows: `Rezuvio-Setup-<versi>.exe` di rilis terbaru. Windows 10 atau 11, 64-bit.
- Tautan "Source code" di halaman rilis dibuat otomatis oleh GitHub dan hanya berisi README ini, bukan app.
- Cara pasang dengan video dan gambar: https://apdannnnn.github.io/rezuvio-rilis/ (juga `Cara-pasang.txt` dan `Cara-pasang-Windows.txt` di halaman rilis).
- Satu kode lisensi untuk 2 komputer (Mac atau Windows), berlaku 1 tahun sejak aktivasi pertama.
- Update kecil diunduh sendiri oleh app.

Kode sumber Rezuvio tidak ada di repositori ini.
